# Changelog

Changes available in this Storybook. Entries describe repository updates, not published package releases.

## Unreleased

### Added

- **Steps:** horizontal and vertical progress, Complete/Current/Upcoming/Error states, narrow-container stacking, and a validated form example.
- **Tooltip:** a component and trigger directive, with placement and theme examples.
- **Collapsible Panel:** expandable content with keyboard interaction and usage examples.
- **Toggle and Toggle Field:** standalone switches and switches with supporting field content.

### Changed

- **Customer Management and Orders:** success and info feedback uses Toasts that auto-dismiss after five seconds. Error Toasts remain until dismissed, and customer loading failures retain a separate Retry control.

- **Storybook navigation:** components now live under Building Blocks or Compositions, grouped by purpose. Theme comparisons are under Foundations, and example screens are under Pages. Charts remain Experimental.
- **Button stories:** consolidated into Playground, Variants & Icons, Sizes, Light, Dark, Interactions and Layout.

### Fixed

- **Button layout:** full-width text buttons fill their container, and long labels can wrap while retaining the minimum size height.

### Upgrade notes

- Storybook navigation changes and consolidated Button stories change story URLs. Update saved links and review affected visual-test baselines.
