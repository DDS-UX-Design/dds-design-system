# Shadows

Shadows add depth and separation to surfaces across desktop and mobile interfaces.
Use the shared shadow token to keep elevation consistent.

## Implementation

The value above is transcribed from the Figma documentation. The Figma `shadow-default`
effect uses a **4px vertical offset** and **8% black opacity**, which differ from the printed
2px offset and 80% opacity. The CSS token follows the effect:

```css
:root {
  --shadow-default: 0 4px 16px 0 rgb(0 0 0 / 8%);
}

.surface {
  box-shadow: var(--shadow-default);
}
```
