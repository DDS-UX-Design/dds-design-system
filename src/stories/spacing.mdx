# Spacing

The DDS spacing scale creates consistent rhythm and alignment across components and layouts. It
follows a **4px base unit**, providing enough flexibility for compact interfaces while keeping
larger compositions visually related.

<div className="dds-spacing__callout">
  <strong>Use tokens instead of one-off values.</strong>
  <span>
    Apply spacing variables to margin, padding, gap, positioning, and layout dimensions so changes
    remain predictable across the system.
  </span>
</div>

## Scale

The scale is shared by desktop and mobile. Responsive layouts change which token is appropriate,
rather than introducing a separate set of spacing values.

## Usage example

```css
.card {
  display: flex;
  flex-direction: column;
  gap: var(--space-4);
  padding: var(--space-6);
}

.page-section + .page-section {
  margin-top: var(--space-9);
}
```

### Good practice

- Use the smallest token that clearly communicates the intended grouping.
- Keep spacing responsibilities at the layout or component-container level.
- Combine spacing with hierarchy, alignment, and typography rather than relying on empty space
  alone.
- Treat touch-target size separately: visible content may be small, but interactive targets should
  remain comfortably operable.
- Avoid negative spacing and arbitrary pixel values unless the exception is documented by the
  component specification.

`--space-none` remains available as a backwards-compatible alias for `--space-0`. New code should
use `--space-0` to match the numbered scale.
